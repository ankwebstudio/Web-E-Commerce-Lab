01 · LEARN

What is a Domain Name?

A domain name is the human-readable address people use to visit a website.

🌐

Example

google.com is a domain name.

Instead of remembering a numerical IP address, users can type a simple domain name into their browser.

Domain Structure

www . example . com
www

Subdomain / host name

example

Main domain name

.com

Domain extension

Common Domain Extensions

.com Commercial
.in India
.org Organization
.net Network
UNDERSTAND

Domain vs URL

DOMAIN

example.com

The main website address.

VS
URL

https://example.com/about

The complete web address of a specific resource or page.

02 · LEARN

What is Web Hosting?

Web hosting is the service that provides the server space and infrastructure needed to make a website available on the internet.

🏠 Hosting

Like the place where your website lives.

+
📍 Domain

Like the address people use to find it.

Common Types of Hosting

👥

Shared Hosting

Multiple websites share resources on the same server.

🖥️

VPS Hosting

A virtual server with dedicated allocated resources.

☁️

Cloud Hosting

Websites use infrastructure distributed across cloud servers.

💡 Remember

A domain and hosting are different things. A website normally needs an address and a place where its files and services run.

CHECK BEFORE CHOOSING

Important Hosting Features

Storage

How much data can be stored.

Bandwidth

How much data can be transferred.

Backups

Options for recovering website data.

SSL

Support for secure HTTPS connections.

Uptime

How consistently the service remains available.

Support

Technical help provided by the hosting provider.

03 · UNDERSTAND

How Domain & Hosting Connect

DNS stands for Domain Name System.

DNS helps direct a domain name to the appropriate server or service.

1 User

Types a domain

→
2 DNS

Finds the destination

→
3 Server

Returns website content

→
4 Website

Appears in browser

💡 Simple way to remember

Domain = Address
Hosting = Place
DNS = Direction system

04 · SECURITY

HTTP vs HTTPS

HTTP

http://example.com

Data is not protected by HTTPS encryption.

VS
HTTPS

https://example.com

Uses TLS encryption to help protect data transferred between the browser and website.

🔒 SSL / TLS

SSL is the older name commonly used when discussing website certificates. Modern secure web connections use TLS.

SECURITY CHECKLIST

Basic Website Security

A website needs more than HTTPS. Good security also involves account, software and backup practices.

05 · DO

Student Practical

Take the website you already created using HTML, CSS, JavaScript and Bootstrap and make it available online. This is your first real website deployment project.

PRACTICAL 01

Publish Your Existing Website

Use your existing website project from the previous web development lessons. Do not create a new website for this activity.

Your task:

  1. Prepare your website files and make sure index.html is the main page.
  2. Check that your CSS, JavaScript, Bootstrap, images and other assets load correctly.
  3. Choose a suitable hosting service for the project.
  4. Upload the website files to the hosting server using the hosting File Manager or another supported method.
  5. Open the temporary hosting URL and verify that the website works correctly.
🌐 Deliverable

Submit the temporary/live website URL and screenshots showing that the website has been successfully uploaded and opened in a browser.

PRACTICAL 02

Connect a Domain to Your Website

Learn how a real domain is connected to the hosting where your website files are stored.

Your task:

  1. Choose a suitable domain name for your project.
  2. Check the domain availability using a domain registrar.
  3. Register a domain if your trainer/institution provides a training domain or if you are using your own project domain.
  4. Find the hosting nameservers or required DNS records.
  5. Connect the domain to the hosting account.
  6. Wait for DNS changes to take effect and test the domain in a browser.
📍 Deliverable

Submit the domain name, hosting provider, connection method used and a screenshot showing the domain opening your website.

PRACTICAL 03

Enable HTTPS and Test the Live Website

Secure the website and verify that visitors can access it through an HTTPS connection.

Your task:

  1. Enable the hosting provider's SSL/TLS certificate for the domain.
  2. Open the website using https://.
  3. Check whether the browser shows a secure connection.
  4. Test whether the HTTP version redirects to HTTPS.
  5. Test the website on desktop and mobile.
  6. Check important pages, navigation links, images, forms and buttons.
🔒 Deliverable

Submit the final HTTPS URL and a short checklist confirming that the website, links, images, responsive layout and HTTPS connection work.

PRACTICAL 04

Basic Website Security Check

Review the security settings of your own website and hosting account.

Check:

  • ✓ HTTPS/SSL is enabled
  • ✓ Hosting account uses a strong password
  • ✓ Two-factor authentication is enabled where available
  • ✓ Website files and backups are maintained safely
  • ✓ Only necessary users have access to the hosting account
  • ✓ Suspicious files, plugins or login attempts are not ignored
⚠️ Important

Students must only perform security checks on websites, hosting accounts and systems they own or have explicit permission to access. Do not scan, attack or attempt to gain unauthorized access to another website.

🚀 Your first real deployment flow

Existing Website → Hosting → Upload Files → Domain → DNS → HTTPS → Live Website
