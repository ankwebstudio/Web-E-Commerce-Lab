SEO for Websites & E-Commerce

Learn how search engines discover, understand and rank website pages. Apply keyword research, on-page SEO, technical SEO and e-commerce SEO to your own student project.

LEARNING OBJECTIVES

What You Will Learn

By the end of this module, students should be able to identify and improve the important SEO elements of a website or online store.

Understand SEO

Understand crawling, indexing, ranking and the role of search intent.

Research Keywords

Identify relevant website, product, location and long-tail keywords.

Apply On-Page SEO

Optimize URLs, titles, headings, content, images, links and meta data.

Check Technical SEO

Understand mobile usability, speed, HTTPS, sitemap, robots.txt, canonical URLs and broken links.

SEO FUNDAMENTALS

How Search Engines Understand a Website

SEO helps search engines discover pages, understand their content and decide which pages are useful for a search.

01

Crawling

Search engines discover and access website pages.

02

Indexing

Search engines process and store information about pages.

03

Ranking

Relevant pages may appear in search results for suitable queries.

SEARCH INTENT

Understand What the User Wants

Before selecting a keyword, understand the reason behind the user's search.

Informational

The user wants to learn something.

"how to choose a website domain"

Commercial

The user is researching before making a decision.

"best website design company Kerala"

Transactional

The user is ready to take an action such as buying or booking.

"buy cotton kurti online Kerala"
KEYWORD RESEARCH

Choose Keywords with a Purpose

Keywords should match the page topic, audience and search intent.

Website Keywords

Keywords describing the main service or website topic.

Product Keywords

Keywords people may use when searching for a specific product.

Location Keywords

Useful for local businesses targeting a particular city, district or area.

Long-Tail Keywords

More specific search phrases that describe a particular need.

ON-PAGE SEO

Optimize the Page Itself

On-page SEO focuses on elements that can be improved directly on the webpage.

SEO-Friendly URL

Keep URLs clear, readable and relevant to the page topic.

Meta Title

Create a clear title that describes the page and its topic.

Meta Description

Write a useful description that encourages relevant clicks.

Headings

Use H1, H2 and H3 headings to create a logical page structure.

Helpful Content

Create useful, relevant content that satisfies the user's need.

Images

Compress images and use meaningful alternative text.

Internal Links

Connect related pages to help users and search engines navigate the site.

CTA

Give visitors a clear next action such as Enquire, Contact, Buy or Book.

LIVE DEMO

Example: Optimize One Product Page

Take one product from the student's WooCommerce store and improve its SEO elements.

PRODUCT SEO EXAMPLE

Product: Women's Cotton Kurti

SEO URL: /womens-cotton-kurti/

Meta Title: Women's Cotton Kurti | Comfortable Everyday Wear

Meta Description: Explore comfortable women's cotton kurtis designed for everyday wear. View styles, sizes and product details.

H1: Women's Cotton Kurti

Image Alt: Women's blue cotton kurti

Internal Link: Link the product to the relevant category page.

TECHNICAL SEO

Make the Website Search-Friendly

Technical SEO focuses on how a website can be accessed, understood and maintained.

Mobile

Check whether important content and navigation work properly on mobile.

Speed

Check loading performance and important Core Web Vitals.

HTTPS

Ensure the website uses a secure HTTPS connection.

XML Sitemap

Understand how an XML sitemap helps search engines discover URLs.

robots.txt

Understand how robots.txt can provide crawling instructions.

Canonical

Understand canonical URLs and their role in duplicate or similar pages.

Broken Links

Identify broken links and unnecessary 404 pages.

Indexing

Check whether important pages can be indexed.

Site Structure

Maintain a logical structure that helps users and search engines.

E-COMMERCE SEO

Optimize Online Store Pages

Product and category pages need useful information so customers and search engines can understand what is being sold.

Product Title

Use a clear product name that accurately describes the item.

Product URL

Keep the URL readable and related to the product.

Product Description

Provide useful, original information instead of thin or copied content.

Product Images

Use suitable image sizes, compression and descriptive alt text.

Category Pages

Create useful category pages with clear names and relevant products.

Related Products

Connect relevant products and categories through useful internal links.

Duplicate Content

Avoid unnecessary duplicate or very thin product content.

Filters & Sorting

Understand how filtering and sorting can create additional URLs that need careful management.

STUDENT PRACTICAL

Optimize Your Own Website

Continue with the same website and e-commerce project used throughout the previous modules.

01

Choose One Target Page

Select one important page from your website or one product page from your WooCommerce store.

  • Identify the page purpose.
  • Identify the target audience.
  • Identify the main search intent.
  • Select a primary keyword.
Deliverable: Page + keyword + search intent.
02

Optimize On-Page SEO

Improve the selected page using the on-page SEO checklist.

  • SEO-friendly URL.
  • Meta title.
  • Meta description.
  • H1/H2 headings.
  • Image alt text.
  • Internal links.
Deliverable: Before/after screenshots.
03

Check Technical SEO

Perform a basic technical SEO check on your website.

  • Mobile usability.
  • Page speed.
  • HTTPS.
  • XML sitemap.
  • robots.txt.
  • Broken links.
Deliverable: Technical SEO checklist.
04

Optimize One E-Commerce Product

Select one WooCommerce product and optimize its SEO elements.

  • Product title.
  • Product URL.
  • Product description.
  • Image alt text.
  • Meta title and description.
  • Internal links.
Deliverable: Optimized product page.
ASSIGNMENT

SEO Optimization Report

Create a short SEO report for one page or product from your project.

Submit

  • Selected page/product and its purpose.
  • Primary keyword and search intent.
  • SEO-friendly URL.
  • Meta title.
  • Meta description.
  • H1/H2 heading structure.
  • Image alt text.
  • At least 2 internal links.
  • Basic technical SEO checklist.
  • Three SEO improvements made.
Expected outcome: Students should be able to identify practical SEO problems and make basic improvements to a website or e-commerce product page.
