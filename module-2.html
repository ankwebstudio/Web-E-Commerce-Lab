01 · LEARN

What is a CMS?

CMS stands for Content Management System.

A CMS allows users to create, edit, organize and manage website content without having to build every part of the website from scratch.

🧩

Simple Example

Imagine a business owner wants to update the text on their About page.

With a CMS, they can usually log into an admin area, edit the content and publish the change without directly editing the website's source code.

What can a CMS help manage?

Pages

About, Services, Contact and other website pages.

Posts

Blog articles and other regular content.

Media

Images, videos and other media files.

Users

Admins, editors and other user roles.

Settings

Website configuration and preferences.

Extensions

Plugins, apps or other additional features.

WordPress

WordPress is a widely used content management system that can be used to create websites, blogs, business websites and, with additional tools, e-commerce websites.

⚙️ Settings

🔌 Plugins

Add or extend website functionality.

03 · PLATFORM

Shopify

Shopify is a hosted e-commerce platform designed to help businesses create and manage online stores.

S
HOSTED E-COMMERCE PLATFORM

Shopify

Shopify provides store management features such as products, inventory, orders, payments and store customization through its platform.

💡 Important

Shopify is different from WordPress because Shopify is a hosted platform. The hosting infrastructure is part of the service, while WordPress itself is software that can be installed on suitable hosting.

05 · APPROACH

What is Custom Development?

Custom development means building a website or web application specifically according to a project's requirements rather than relying entirely on a pre-built CMS structure.

🛠️

When custom development may be considered

A project may need custom development when it has specialized workflows, integrations, functionality or technical requirements that are not easily handled by an existing platform.

Common characteristics

Custom Features

Functionality can be designed around specific requirements.

Custom UI

Interface and user experience can be built specifically for the project.

Integrations

Specialized systems and APIs can be integrated.

Development Effort

Usually requires more technical planning and development work.

COMPARE

CMS, E-Commerce Platform or Custom?

There is no single solution for every client. The correct approach depends on the project's requirements.

Option
Typical Use
Management
Considerations
WordPress Business websites, blogs, content websites Dashboard-based management Hosting, themes and plugins need management
Shopify Online stores Hosted store management Platform-based features and ecosystem
WooCommerce WordPress-based online stores WordPress + WooCommerce dashboard More control, but more components to manage
Custom Development Specialized websites and web applications Custom admin/development workflow Greater development effort and responsibility
CLIENT REQUIREMENT

Ask Before You Choose

01

What does the client need?

Business website, blog, online store or custom application?

02

Who will manage it?

Will the business owner or a marketing team update the website?

03

What features are required?

Products, bookings, memberships, integrations or other workflows?

04

What are the constraints?

Consider budget, timeline, maintenance and technical requirements.

🎯 Key idea

Don't choose a platform first and then force the client's requirements into it. Understand the requirements first, then select an appropriate approach.

06 · DO

Student Practical

Use your own website project and a WordPress practice installation to understand how a CMS works in real use.

PRACTICAL 01

Set Up a WordPress Practice Website

Use a WordPress installation provided by your trainer or create a practice installation on suitable hosting. Do not use a live client website for experimentation.

Complete these steps:

  1. Log in to the WordPress admin dashboard.
  2. Identify the website URL and admin URL.
  3. Explore the Dashboard.
  4. Open Pages, Posts, Media, Users, Settings and Plugins.
  5. Identify which areas a digital marketer would use regularly.
📄 Deliverable

Submit screenshots of the WordPress dashboard and prepare a simple table showing each section, its purpose and one practical marketing use.

PRACTICAL 02

Recreate Your Existing Website in WordPress

Take the website you already created using HTML, CSS, JavaScript and Bootstrap. Recreate the basic structure of that website in WordPress.

Suggested workflow:

  1. Review your existing website pages.
  2. Create the same or equivalent pages in WordPress.
  3. Add your text and images through the WordPress dashboard.
  4. Create the main navigation menu.
  5. Set the homepage and basic site information.
  6. Preview the website on desktop and mobile.
💡 Learning goal

The objective is not to copy code into WordPress. Students should understand how the same website content can be managed through a CMS dashboard instead of editing every page manually.

📄 Deliverable

Submit the WordPress website URL or staging URL, screenshots of the main pages and a short note explaining what changed compared with the original custom website.

PRACTICAL 03

Manage Website Content from the Dashboard

Practice common content-management tasks that a digital marketer may perform after a website is live.

Perform these tasks:

  1. Edit the About page.
  2. Add or replace an image in Media.
  3. Create one blog post.
  4. Add a suitable featured image.
  5. Create or edit a navigation item.
  6. Preview and publish the changes.
📄 Deliverable

Submit before-and-after screenshots showing at least two content changes made through WordPress.

PRACTICAL 04

Compare Custom Website vs WordPress

Compare the original HTML/CSS/JavaScript/Bootstrap website with the WordPress version you created.

Compare:

  1. How content is added or edited
  2. How images are managed
  3. How pages are managed
  4. How plugins or additional features are added
  5. Who can manage the website
  6. Maintenance requirements
📄 Deliverable

Create a one-page comparison table and write 3–5 observations from your own practical work.

PRACTICAL 05

Platform Selection Activity

Now apply what you learned to different client situations. Do not select a platform only because you know how to use it.

Scenario A

A local restaurant needs a simple website with menu, About, location and contact information.

Scenario B

A fashion business wants to sell products online and manage inventory and orders.

Scenario C

A company needs a specialized web application with a unique internal workflow.

📄 Your Task

For each scenario, identify a possible platform or development approach and explain your reasoning using the client's requirements.
