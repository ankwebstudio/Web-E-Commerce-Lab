01 · LEARN

What is a Domain Name?

A domain name is the human-readable address people use to visit a website.

🌐

Example

google.com is a domain name.

Instead of remembering a numerical IP address, users can type a simple domain name into their browser.

Domain Structure

www . example . com
www

Subdomain / host name

example

Main domain name

.com

Domain extension

Common Domain Extensions

.com Commercial
.in India
.org Organization
.net Network
UNDERSTAND

Domain vs URL

DOMAIN

example.com

The main website address.

VS
URL

https://example.com/about

The complete web address of a specific resource or page.

02 · LEARN

What is Web Hosting?

Web hosting is the service that provides the server space and infrastructure needed to make a website available on the internet.

🏠 Hosting

Like the place where your website lives.

+
📍 Domain

Like the address people use to find it.

Common Types of Hosting

👥

Shared Hosting

Multiple websites share resources on the same server.

🖥️

VPS Hosting

A virtual server with dedicated allocated resources.

☁️

Cloud Hosting

Websites use infrastructure distributed across cloud servers.

💡 Remember

A domain and hosting are different things. A website normally needs an address and a place where its files and services run.

CHECK BEFORE CHOOSING

Important Hosting Features

Storage

How much data can be stored.

Bandwidth

How much data can be transferred.

Backups

Options for recovering website data.

SSL

Support for secure HTTPS connections.

Uptime

How consistently the service remains available.

Support

Technical help provided by the hosting provider.

03 · UNDERSTAND

How Domain & Hosting Connect

DNS stands for Domain Name System.

DNS helps direct a domain name to the appropriate server or service.

1 User

Types a domain

→
2 DNS

Finds the destination

→
3 Server

Returns website content

→
4 Website

Appears in browser

💡 Simple way to remember

Domain = Address
Hosting = Place
DNS = Direction system

04 · SECURITY

HTTP vs HTTPS

HTTP

http://example.com

Data is not protected by HTTPS encryption.

VS
HTTPS

https://example.com

Uses TLS encryption to help protect data transferred between the browser and website.

🔒 SSL / TLS

SSL is the older name commonly used when discussing website certificates. Modern secure web connections use TLS.

SECURITY CHECKLIST

Basic Website Security

A website needs more than HTTPS. Good security also involves account, software and backup practices.

05 · DO

Student Practical

Apply what you learned by researching real domain names and evaluating website security.

PRACTICAL 01

Domain Selection Activity

Imagine that you are creating a website for a new business.

Your task:

  1. Choose a fictional business.
  2. Create 3 possible domain names.
  3. Check whether the domains are available using a domain registrar.
  4. Compare the domain extensions.
  5. Select your preferred domain.
  6. Write 2–3 reasons for your choice.
📄 Deliverable

Submit a simple table containing: Business Name, Domain Option, Extension, Availability and Reason.

PRACTICAL 02

Website Security Checklist

Choose a website and review its publicly visible security indicators.

Check:

  • ✓ Does it use HTTPS?
  • ✓ Does the browser show a secure connection?
  • ✓ Does the website redirect from HTTP to HTTPS?
  • ✓ Does the website appear to use updated software? (where publicly observable)
⚠️ Important

Students should only observe publicly available information. Do not attempt to test, scan or attack websites without explicit permission.
