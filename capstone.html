PROJECT OBJECTIVE

What You Will Build

The capstone brings together the practical skills from the complete course into one real-world project.

Plan

Select a business, identify the audience, define the goal and create the website structure.

Build

Create a custom website or build and manage a website using WordPress.

Create

Use AI responsibly to create useful website, product and marketing content.

Optimize

Apply SEO, connect Search Console and complete a final website audit.

PROJECT ROADMAP

Build Your Project Step by Step

Follow these steps from business selection to final SEO audit.

01

Choose a Business

Select one real or imaginary business for your complete project.

  • Choose a business type.
  • Identify the target audience.
  • Define the main business goal.
  • Decide whether the website needs e-commerce.
Student Deliverable Business Name + Business Type + Target Audience + Main Goal
02

Domain & Hosting Setup

Choose the appropriate publishing path based on how your website is built.

  • Select a suitable domain name.
  • Understand the difference between domain and hosting.
  • Select the correct hosting method.
  • Publish the website and test HTTPS.
Choose Your Deployment Path Custom Website → GitHub Pages | WordPress → WordPress-compatible Hosting
03

Plan Website Structure

Use the planning process from Module 3 before building the website.

  • Define the website pages.
  • Create navigation.
  • Create categories and subcategories.
  • Plan the user journey.
  • Create a sitemap.
Student Deliverable Website sitemap + navigation structure
04

Build the Website

Choose one of the two website development approaches below.

  • Custom HTML/CSS/JavaScript/Bootstrap website OR
  • WordPress website
  • Create the required pages.
  • Add header, footer and navigation.
  • Make the website responsive.
05

Add E-Commerce

If your selected business sells products, create the e-commerce part of the project.

  • Create product categories.
  • Add products.
  • Add simple or variable products.
  • Configure cart and checkout.
  • Test the customer journey.
WordPress Projects Use WooCommerce for the e-commerce section.
06

Create AI-Assisted Content

Use AI as a content creation assistant, not as a replacement for human review.

  • Create homepage content.
  • Create product or service descriptions.
  • Generate blog ideas.
  • Create CTA and marketing copy.
  • Fact-check and edit AI output.
Student Deliverable AI prompt + final edited content
07

Apply SEO

Optimize the website for search engines using the concepts from Module 6.

  • Perform basic keyword research.
  • Optimize SEO titles and meta descriptions.
  • Optimize URLs and headings.
  • Add image alt text.
  • Add internal links.
  • Check mobile usability, HTTPS and broken links.
08

Connect Search Console & SEO Tools

Use SEO tools to understand how the website can be improved.

  • Connect Google Search Console.
  • Inspect an important URL.
  • Check indexing status.
  • Analyse search queries and performance.
  • Audit a page using SEO tools.
09

Complete the Final SEO Audit

Review the complete website and document the most important improvements.

  • Find website problems.
  • Collect evidence.
  • Set priority.
  • Recommend an action.
  • Explain the expected result.
Audit Format Problem → Evidence → Priority → Action → Expected Result
DEPLOYMENT OPTIONS

Choose Your Website Path

The deployment method depends on how you created your website. Choose the path that matches your project.

Custom Website

HTML + CSS + JavaScript + Bootstrap

1 Create your website files
2 Purchase a domain through Square Brothers
3 Create a GitHub repository
4 Upload your website files
5 Enable GitHub Pages
6 Connect the custom domain
7 Configure DNS records
8 Test HTTPS and the live website
Recommended Course Setup

Domain: Square Brothers
Hosting: GitHub Pages

Square Brothers GitHub Setup Guide

WordPress Website

WordPress + WooCommerce

1 Choose and purchase a domain
2 Choose WordPress-compatible hosting
3 Connect the domain to your hosting
4 Install WordPress
5 Open WordPress Admin Dashboard
6 Build pages and navigation
7 Install WooCommerce if required
8 Enable SSL and test the live website
Important

GitHub Pages is not used for WordPress hosting. WordPress requires a hosting environment that supports WordPress.

Domain Guide Hosting Guide WordPress Guide
PLANNING CHECKPOINT

Plan Before You Build

Students should complete the planning stage before starting the actual website development.

Business Goal

What should the website help the business achieve?

  • Generate enquiries
  • Sell products
  • Promote services
  • Build brand awareness

Target Audience

Identify who the website is designed for.

  • Age / customer group
  • Location
  • Customer needs
  • Search intent

Sitemap Example

Home ├── About ├── Products │ ├── Category 1 │ ├── Category 2 │ └── Category 3 ├── Blog ├── Contact └── Privacy Policy

User Journey

Home ↓ Products / Services ↓ Category ↓ Product / Service ↓ CTA ↓ Enquiry / Purchase
FINAL CHECKLIST

Before You Submit

Use this checklist to make sure your project is complete.

  • Business goal is clearly defined.
  • Target audience is identified.
  • Website sitemap is completed.
  • Navigation works correctly.
  • Website is responsive.
  • Domain and hosting are configured.
  • HTTPS is working.
  • Products and categories are added if required.
  • Cart and checkout are tested if applicable.
  • AI-generated content has been reviewed.
  • SEO titles and meta descriptions are added.
  • Images have suitable alt text.
  • Internal links are checked.
  • Google Search Console is connected.
  • Important URL has been inspected.
  • Final SEO audit is completed.
