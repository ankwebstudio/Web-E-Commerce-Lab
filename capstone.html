Final Project

Build One Complete Website

Put everything you learned together by planning, building, publishing and optimizing one complete business website.

View Project Roadmap Back to Learning Portal
Project Objective

From Idea to Live Website

Your final project should demonstrate that you can plan, create, publish and improve a real business website.

Choose a real or imaginary business and create a complete website for it. You may build the website using custom HTML/CSS/JavaScript/Bootstrap or WordPress.

  • Define the business and target audience
  • Plan pages and website structure
  • Build and publish the website
  • Add e-commerce features when required
  • Create content using AI responsibly
  • Optimize the website for SEO
  • Connect Google Search Console
  • Perform a final website audit

Website Setup

Choose Your Website Path

You can complete the project using either custom development or WordPress.

Option A — Custom Website

Build your website using HTML, CSS, JavaScript and Bootstrap.

  • Create website files
  • Test website locally
  • Upload project to GitHub
  • Enable GitHub Pages
  • Purchase a custom domain
  • Connect domain with GitHub Pages
  • Enable HTTPS
  • Test the live website
Domain Guide GitHub Pages Guide

Option B — WordPress

Build and manage the website using WordPress and a suitable hosting environment.

  • Choose a domain
  • Choose WordPress-compatible hosting
  • Install WordPress
  • Login to WordPress Dashboard
  • Choose a theme
  • Create pages and navigation
  • Add required plugins
  • Add WooCommerce if required
  • Configure SEO and publish

Project Requirements

What Your Website Should Include

Your final website should be complete enough to demonstrate practical web skills.

Homepage

Clear business introduction, value proposition and CTA.

Important Pages

About, Services or Products, Contact and other relevant pages.

Navigation

Simple navigation that allows users to find important information quickly.

Responsive Design

Website should work properly on mobile, tablet and desktop.

CTA

Include suitable actions such as Call, WhatsApp, Enquire or Buy.

SEO

Apply basic on-page and technical SEO before final submission.

E-Commerce Option

If Your Project Is an Online Store

Add an e-commerce flow that allows users to discover products and complete an order.

Categories

Create relevant product categories and subcategories.

Products

Add products with title, description, images and pricing.

Cart

Test adding products to the shopping cart.

Checkout

Test the checkout process and required customer information.

Orders

Demonstrate how an order can be viewed and managed.

Product Discovery

Use categories, filters, sorting or related products where appropriate.

Final Checklist

Before You Submit

Complete this checklist before submitting your project.

Website opens correctly using the final URL.
All important pages are accessible.
Navigation and buttons work correctly.
Website is responsive on mobile and desktop.
Images are optimized and have suitable alt text.
Page titles and meta descriptions are added.
Important URLs are SEO-friendly.
HTTPS is working correctly.
E-commerce flow works if applicable.
Google Search Console is connected.
Final SEO audit is completed.
Final Audit

Report Problems Like a Digital Marketer

Do not simply list problems. Explain the evidence, priority and recommended action.

Problem: What is wrong?
Evidence: What did you observe?
Priority: High, Medium or Low?
Action: What should be changed?
Expected Result: What improvement do you expect?

Final Submission

Submit your completed website along with the information below.

  • Live website URL
  • GitHub repository URL (for custom websites)
  • Website structure / sitemap
  • SEO audit report
  • Search Console evidence
  • Important screenshots
