Step 01

What is WordPress?

WordPress is a content management system (CMS) used to create and manage websites without manually coding every page.

In this course

You will use WordPress to build and manage a practical business website. You will learn how to manage content from the dashboard, install themes and plugins, and add e-commerce functionality when required.

Domain → Hosting → WordPress → Website → SEO → Publish
Step 02

WordPress.com vs WordPress.org

These are related to WordPress, but they are not the same setup.

WordPress.com WordPress.org
Hosted platform WordPress software that you install on your own hosting
Hosting is managed by the platform You choose your hosting provider
Setup depends on the selected plan More control over website, plugins and hosting
Good for learning the hosted service Suitable for learning self-hosted WordPress
For this practical project

We are learning the self-hosted WordPress workflow: choose hosting → install WordPress → manage the website from the dashboard.

Step 03

Domain & Hosting

Before installing WordPress on a live website, you need a domain and suitable hosting.

1

Choose a Domain

Choose a short, relevant and easy-to-remember domain name for your project.

  • Keep it simple.
  • Avoid unnecessary numbers and symbols.
  • Choose an extension suitable for the project.
2

Choose Hosting

Choose hosting that supports WordPress and provides the resources required for your project.

  • WordPress support
  • SSL/HTTPS
  • Database support
  • Control panel
  • Backup and security options
Domain / Hosting Provider
Step 04

Install WordPress on Hosting

Most WordPress-compatible hosting providers offer an installer from the hosting control panel.

1

Login to Hosting Control Panel

Use the login details provided by your hosting provider.

2

Find the WordPress Installer

Look for a WordPress installer or application installer in the hosting dashboard.

3

Enter Website Details

  • Website name
  • Admin username
  • Strong admin password
  • Admin email
4

Complete Installation

Complete the installation and open your WordPress admin area.

Step 05

Login to WordPress Dashboard

After installation, use the WordPress admin login page to manage your website.

Common admin URL

https://yourdomain.com/wp-admin

Security Tip

Never share your WordPress admin password with others. Use a strong password and enable additional security where available.

Step 06

Understand the WordPress Dashboard

The dashboard is the control area from which you manage your website.

Posts Create and manage blog content.
Pages Create static website pages.
Media Upload and manage images and files.
Appearance Manage themes and website appearance.
Plugins Add additional website functionality.
Settings Configure important website settings.
Step 07

1

2

Choose a Suitable Theme

  • Mobile responsive
  • Clean navigation
  • Easy to customize
  • Good performance

Step 10

Install and Manage Plugins

Plugins add additional functionality to WordPress.

Examples

Contact forms, SEO, security, caching, analytics, e-commerce and other features can be added through suitable plugins.

Important

Do not install unnecessary plugins. Too many plugins can make website management and maintenance more difficult.

Step 15

Apply Basic SEO

Your WordPress website should be optimized so search engines can understand and discover it.

SEO Title Create a clear and relevant page title.
Meta Description Write a useful description that matches the page content.
URL Keep URLs short and meaningful.
Headings Use logical H1, H2 and H3 structure.
Images Compress images and add useful alt text.
Internal Links Connect related pages naturally.
Continue with Module 6 & Module 7

Use the SEO concepts from Module 6 and the tools and Search Console workflow from Module 7 to complete the optimization and audit.

Step 16

Basic Security & Backup

Website security is part of responsible website management.

  • Use a strong administrator password.
  • Keep WordPress updated.
  • Keep themes and plugins updated.
  • Remove unused plugins and themes.
  • Use HTTPS.
  • Maintain regular backups.
  • Use appropriate user roles.
Step 17

Test the Website

Before publishing the final project, test the website as a real visitor would use it.

  • Homepage loads correctly.
  • Navigation links work.
  • Contact form works.
  • Images load correctly.
  • Website works on mobile.
  • HTTPS works correctly.
  • Product pages work if e-commerce is used.
  • Cart and checkout flow are tested if applicable.
Step 18

Publish the Website

Once the website is complete and tested, it is ready to be presented as your final project.

Build → Test → SEO → Search Console → Audit → Submit
