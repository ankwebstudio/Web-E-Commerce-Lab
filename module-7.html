SEO TOOLKIT

Four Tools You Should Know

Students do not need to learn every feature. Focus on the features that are useful for everyday Digital Marketing work.

Google Search Console

A Google platform for monitoring a website's search visibility and understanding indexing and search performance.

  • Search queries
  • Clicks and impressions
  • CTR and position
  • URL Inspection
  • Indexing information
Priority Tool

SEO Minion

A browser-based tool useful for quickly checking important on-page SEO elements.

  • Links
  • Broken links
  • SERP preview
  • Basic page analysis

SEMrush

A broader SEO and digital marketing platform useful for keyword, competitor and website research.

  • Keyword opportunities

Practical Search Console Workflow

Search Console is the most important tool in this module because it provides first-party information about how a website performs in Google Search.

Connect

Add and verify the website property in Search Console.

02

Inspect

Use URL Inspection to check an important page and its indexing status.

03

Analyse

Review queries, clicks, impressions, CTR and position.

04

Improve

Identify useful SEO improvements from the data.

UNDERSTAND THE DATA

What Do These Numbers Mean?

Clicks How many times users clicked the website from Google Search.
Impressions How many times a website result was shown in Google Search.
CTR The percentage of impressions that resulted in clicks.
Average Position An average position metric for the site's results in the selected Search Console data.
Queries Search terms for which the website received impressions or clicks.
STUDENT PRACTICAL

Use the Tools on Your Own Project

Students should work with the same website created and optimized during Modules 1–6.

01

Connect Google Search Console

Connect the student's website to Google Search Console.

  • Add the website property.
  • Complete verification.
  • Open the Search Console dashboard.
  • Locate Performance and URL Inspection.
Deliverable: Screenshot of verified property/dashboard.
02

Inspect One Important URL

Select an important page or product and inspect it using URL Inspection.

  • Enter the URL.
  • Check the inspection result.
  • Identify indexing information.
  • Record any issue shown.
Deliverable: URL Inspection screenshot + observation.
03

Analyse Search Queries

Use the Performance report to understand how the website appears in Google Search.

  • Find search queries.
  • Note clicks.
  • Note impressions.
  • Check CTR and position.
  • Identify useful queries.
Deliverable: Five useful search queries.
04

Audit a Page with SEO Minion

Use SEO Minion to perform a quick page-level SEO check.

  • Check headings.
  • Check links.
  • Check broken links.
  • Review SERP preview.
Deliverable: Three observations from the audit.
05

Research with SEMrush or Ahrefs

Use an available free/trial/demo feature to explore keywords or competitors.

  • Search a relevant keyword.
  • Observe related keywords.
  • Explore competitor information.
  • Note one content opportunity.
Deliverable: Keyword/competitor research screenshot.
06

Find 3 SEO Improvements

Combine the information from the tools and identify three useful improvements.

  • One content improvement.
  • One on-page improvement.
  • One technical or indexing improvement.
Deliverable: Three prioritized SEO actions.
FINAL AUDIT

From Data to Action

The goal is not simply to generate an SEO report. Students should use the information to decide what needs to be improved first.

Problem What SEO issue did you find?
Evidence Which tool or observation showed the problem?
Priority Is this a high, medium or low priority issue?
Action What specific change should be made?
Expected Result What improvement do you expect from the action?
ASSIGNMENT

Mini SEO Audit Report

Prepare a short SEO audit using the tools introduced in this module.

Submit

  • Website/project URL.
  • Google Search Console screenshot.
  • One URL Inspection result.
  • Five useful search queries or keyword observations.
  • SEO Minion audit observations.
  • One SEMrush or Ahrefs research observation.
  • Three SEO problems or opportunities.
  • Three recommended actions.
  • Priority for each action.
Final Deliverable: A short SEO Audit Report showing Problem → Evidence → Priority → Action .
